ГИС ЖКУ — учёт лицевых счетов, организаций и адресов. Версия 1.7.1

СТРУКТУРА ПРИЛОЖЕНИЯ
  app.py            — основное приложение (Flask)
  requirements.txt  — зависимости
  templates/        — HTML-шаблоны страниц (10 файлов)
  forms/            — макеты отчетов Excel:
                      «Форма отчета.xlsx»  — детальный отчет по адресу
                      «Отчет таблица.xlsx» — сводная таблица по найденным адресам
                      (макеты восстановлены по структуре; свои оригиналы можно положить
                       в папку forms/ под теми же именами — они будут использоваться)
  data/             — база app.db, резервные копии (data/backups), журнал app.log
  шаблоны/          — генерируемые шаблоны импорта (создается автоматически)

УСТАНОВКА
  1. Распакуйте архив в папку приложения (например E:\gis_zkhu_app).
  2. python -m pip install -r requirements.txt
  3. python app.py
  4. Откройте http://127.0.0.1:5000

ЧТО НОВОГО В 1.7.1
  1. Поиск по части адреса (кнопка «Поиск по части адреса» на главной и на странице «Поиск»):
     - слова запроса ищутся в порядке следования, между ними могут быть любые символы;
     - регистр и буква «ё/е» не имеют значения;
     - при пустом поле выводится сообщение «Не заполнены данные для поиска», кнопка
       «Отмена» закрывает окно;
     - у каждого найденного адреса кнопка «Отчет» — формирует «Форму отчета» по адресу;
     - кнопка «Создать таблицу по всем найденным адресам» формирует сводную таблицу.
  2. Восстановление базы из резервной копии (Администрирование -> Обслуживание):
     - перед восстановлением автоматически создается предохранительная копия pre_restore_...;
     - файл проверяется на соответствие базе приложения, посторонние файлы отсекаются.
  3. Улучшенный разбор адреса: «ст-ца» с точкой и без, ЖК/СНТ/ДНП/ТСЖ/ЖСК/КП в отдельном
     поле «Структура», «ком.»/«комн.» без висячих точек, дом без «д.», голый город
     («Геленджик, ул. Лунная, 7/1»).

РЕЗЕРВНОЕ КОПИРОВАНИЕ
  Кнопка «Создать резервную копию» в разделе «Администрирование» кладет копию в data/backups.
  Восстановление — из этого же раздела.
